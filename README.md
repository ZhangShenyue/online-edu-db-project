\# 在线教育学习行为数据库设计与性能优化项目

本项目基于MySQL + Redis实现，完成数据库建模、索引优化、事务并发控制、视图查询、Redis缓存二级加速对照实验。



\## 项目介绍

本项目模拟在线教育平台学生学习数据，设计数据表，生成批量模拟测试数据，完成多组数据库性能优化实验，最后引入Redis旁路缓存做读请求加速。



\## 功能模块

1\. \*\*数据库建模与模拟数据生成\*\*

设计用户、课程、学习记录数据表，Java程序批量生成海量模拟测试数据，用于压力测试。



2\. \*\*索引优化对照实验\*\*

对比有无索引情况下SQL查询耗时，验证索引对查询性能的提升效果。



3\. \*\*事务与并发实验\*\*

测试数据库事务隔离级别、悲观锁、模拟并发场景，复现并发问题，理解数据库锁机制。



4\. \*\*视图 v\_student\_study\_stats\*\*

创建数据库视图，封装学生学习统计信息：已修课程数量、已完成任务数、平均分。



5\. \*\*Redis缓存优化（Cache Aside旁路缓存）\*\*

针对学生统计高频点查场景，引入Redis构建二级缓存。

查询逻辑：优先读取Redis，缓存未命中时查询MySQL视图，并将结果写入缓存，设置过期时间保证最终一致性。



\### 缓存对照实验结果

循环查询同一学生统计数据100次

\- 直接查询数据库视图：总耗时5003ms，单次平均：50.03ms

\- 使用Redis缓存查询：总耗时55ms，单次平均：0.55ms

\- \*\*性能提升约90.96倍\*\*



\## 技术栈

Java、JDBC、MySQL、Redis、Jedis、Maven



\## 运行环境

\- Java 8

\- MySQL 8.0

\- Redis 服务端（本地6379端口）

\- Maven



\## 运行步骤

1\. 启动Redis服务端 redis-server

2\. 执行SQL脚本，创建数据表与视图

3\. 运行Java程序生成测试数据

4\. 依次运行各测试类：索引测试、事务并发测试、Redis缓存性能对比测试
